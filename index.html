Battery types

Write the type name, then = and the characters the serial number starts with. Separate several codes with commas. Put * in front of a code if it can sit anywhere in the serial number. A type without codes is only in the list.
Creates names like S1-A-01 (side 1, layer A, section 1). This replaces the list below; you can still edit it by hand.
Write the location name, then = and the maximum number of batteries (leave it out for no maximum). For a dedicated area add "for Defect", "for Marketing" or "for anything", for example: REP = for Defect. Crates are not in this list: manage them under Settings → Crates.

Batteries idle for 3 months or more

In stock and not charged for 3 months or more, counted from the check-in or the last charge. Charge the battery, then press Charged: its 3 months start again. Tap a row to see the battery.

Boxes

Boxes stand in stacks on side 1 and side 2, box 1 at the bottom and at most 6 high. Each box is one storage location named after its sticker, e.g. 1-A-3. Put a box on top of a stack or take the top box off; the history log is always kept.
