Tap Scan and hold the barcode in front of the camera; it is read by itself. You can also paste or drag a photo onto this form, or use a handheld barcode scanner.
Every field is required except Reference nr and Note.
Auto checks a battery out when it is in stock, and in when it is not. The fields start empty for every battery, so each one is filled in on purpose. The type is filled in from the serial number when it is recognised. When Auto checks a battery out, it keeps that battery's recorded status, purpose and in-box.

Battery types and storage locations

Write the type name, then = and the characters the serial number starts with. Separate several codes with commas. Put * in front of a code if it can sit anywhere in the serial number. A type without codes is only in the list.
Creates names like S1-A-01 (side 1, layer A, section 1). This replaces the list below; you can still edit it by hand.
Write the location name, then = and the maximum number of batteries (leave it out for no maximum). For a dedicated area add "for Defect", "for Marketing" or "for anything", for example: REP = for Defect
